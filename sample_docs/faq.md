# Project Atlas – FAQ

**Q: Who do I contact with questions about the project?**
A: Maria Keller, the engagement lead. For technical questions, contact Jonas Weber.

**Q: When will Project Atlas go live?**
A: The target go-live date is 1 March 2027. A pilot with 5 support agents starts on 15 January 2027.

**Q: Can Project Atlas read tickets from Slack?**
A: Not at first. Slack ticket intake is planned for Phase 2, after go-live. Phase 1 only uses email.

**Q: Will the assistant send replies to customers automatically?**
A: No. The assistant only suggests replies. A human agent must review every reply before it is sent.

**Q: Where is ticket data stored?**
A: Only inside the client's own environment. Ticket data is never sent to external servers.

**Q: Which languages does the assistant support?**
A: German and English.
